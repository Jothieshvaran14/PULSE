## 8. Incidents and notes

### 8.1 Docker daemon outage (environmental, not code)
The Docker Desktop engine stopped between the baseline and the Wave A gate; `test:integration` failed with `Can't reach database server at localhost:5432`. Docker Desktop was restarted (ready in 5 s), the same unchanged tree re-ran **exit 0**. Recorded rather than hidden; no test was altered.

### 8.2 BOM in `routes.yml` (caught pre-push)
A PowerShell `Set-Content -Encoding utf8` added a UTF-8 BOM. It was detected in the diff, stripped with a byte-level fix, and the **local, unpushed** commit was amended. The pushed commit contains only the 5-line router deletion.

### 8.3 Commit author PII (needs a D7 decision)
The local git identity carried a personal Gmail address, so every commit from Phase 0.2 onward (`a7297cb`…`edc9a18`) has that author email. The unpushed commit was re-authored to the GitHub noreply address and `user.email` is now `jothieshvaran14@users.noreply.github.com` for all future commits. **No history rewrite was performed** (forbidden). The repository is private, and this is the owner's own address; remediation (noreply masking of pushed commits) is exactly **D7**, which remains ⛔ not authorized.

### 8.4 Compose topology
The running stack predates the unified compose file: Traefik belongs to legacy project `ryme` (`docker-compose.traefik.yml`), Postgres to project `docker`. Fixes were applied through the matching project; the config files are now consistent for a future single-project `pnpm infra:up`.
